# UNFILED

**まだ、何者でもないアイデアたち。**

AIと一緒に、思いつくままにつくった世界の入口。テーマの揃わない作品を、ひとつの空間から自由に見つけるための、XenithONEの制作物ポートフォリオです。

React・TypeScript・Viteで構築し、GitHub Pagesへ静的サイトとして公開します。ハブは three.js の `WebGPURenderer` と TSL（Three Shading Language）で描く、ひとつの景色です。夕暮れの浅い水鏡に作品が光る板として立ち、歩くうちに一晩が過ぎていきます。空・星・雲・水面、それに宙を漂う光の粒は、すべて数式がその場で描き、画像は作品の表紙だけです。

## ローカルで開く

Node.js 22.12以降を使用してください。このフォルダーを開き、次のコマンドを実行します。

```sh
npm ci
npm run dev
```

ターミナルに表示されたローカルURLで開きます。公開用ファイルの確認は次のとおりです。

```sh
npm run build
npm run preview
```

## 体験の構成（ハブ v5「水鏡のアーカイブ」）

ハブは 1 枚の固定キャンバスに描く 3D の景色で、スクロールがそのまま「歩くこと」になります。場所は、空を映す浅い水（塩の平原の上の数ミリの水）。入口から出口まで歩くあいだに、夕方から夜を通って朝になります。

- **起動**: 端末の方式（WebGPU / WebGL2）を表示するブートシーケンスのあと、水面を見下ろす高さからカメラが降りてきて、冒頭の構図に落ち着きます。そのあいだ、光の粒が集まって題字「UNFILED」を点描で描いています。
- **冒頭**: 黒い鋼の立体文字「UNFILED」が水に立ち、夕日が「L」の切り欠きに収まっています。文字も雲も太陽も水面に映り、太陽からこちらへ光の道が伸びます。右上に WIP のスタンプ。カメラが落ち着くと粒の大半は文字を離れて宙へ戻り、鋼の面にはまばらな光だけが残ります。ときどき、粒の一陣が文字を左から右へ横切ります。
- **歩く**: 35 の作品は、内側から光る板（ライトボックス）として U 字の道沿いに並びます。スクロールで 1 作品ずつ板の前に止まり、左下に作品名（1 文字ずつ組み上がる）と副題、「ひらく」ボタン。止まった板はいったん灯りを落とし、宙の粒が飛んできて表紙を光の点で描き、そのあと板そのものが点灯します（粒は離れて、表面にわずかなきらめきだけが残ります）。右端のレールが現在位置です。進むにつれて、夕焼け → 残照 → 薄明 → 星空と天の川 → 夜明け前 → 日の出へと空が変わり、左下の計器に 18:42 から 05:52 までの時刻が出ます。夜は流れ星が落ちます。
- **触れる**: ポインターが水面をなでると波紋が広がり、映り込みが揺れます。夜は波紋が冷たく光ります。ポインターの近くの粒は、よけて渦を巻きます。遠くの板にポインターを合わせると番号と作品名が出て、クリックするとその板まで歩きます。目の前の板をクリックすると詳細が開きます。
- **詳細**: 「ひらく」（Enter）でカメラが板に寄り、紹介文・作品へのリンク・ソースへのリンク・前後の作品への移動が出ます。URL の `#作品ID` で直接開けます。
- **索引**: 「作品の索引」（I キー）で 35 作品をタイルで一覧し、世界／ゲーム／道具／物語で絞り込めます。タイルを選ぶとその作品の位置へ移動します。
- **おまかせ散歩**: 右下の TOUR（T キー）で、一晩ぶんの道のりを自動で歩きます（約 3 分半）。ホイール・タッチ・矢印キーで自分の操作に戻ります。H キーは文字を隠して景色だけにします。
- **終章**: 最後の板の先でカメラは開けた水面に向き、この場所の説明を読むあいだに日が昇ります。粒は明け方の空に「好奇心に、完成はない。」と書きます（説明の文字が画面を埋める幅の狭い画面では書きません）。
- **音**: 右下の SND で生成音（音声素材なし・Web Audio）が鳴ります。歩く速さで強まる風、近くの水音、時刻とともに移り変わる和音、作品に着いたときの鐘。既定はオフで、選択は記憶します。
- **操作**: ↑↓（←→）で前後の作品、Enter で詳細、I で索引、T でおまかせ散歩、H で文字を隠す、Esc で戻る、Home / End で先頭と終章。タッチ端末では通常のスクロールで進み、画面上部に板、下部に作品名が出ます。
- **端末対応**: 画質は 4 段階（解像度の上限・映り込みの解像度・多重サンプリング・空の細かさ・表紙の大きさ・光の粒の数＝約 41 万 / 26 万 / 15 万 / 6.5 万）から自動で選び、重いときは描画解像度を自動で下げます。WebGPU が無ければ WebGL2 で同じ景色を描き、どちらも無ければ索引を本文として並べます。OS の「視差効果を減らす」設定では、カメラの揺れ・波紋・星のまたたき・文字のアニメーションを抑え、粒が群れて飛ぶ演出（表紙を描く・空に書く・文字を横切る）をやめて、宙に漂わせるだけにします。

### 仕組みの要点（開発者向け）

- `src/stage/Stage.ts` — レンダラー・カメラの道のり（冒頭 → 作品ごとの停止位置 → 終章、詳細表示）・スクロール量から時刻への対応・後処理（ブルーム・周辺減光・文字の下の陰り・粒状）・ポインター（波紋・ホバー・選択）。
- `src/stage/sky.ts` — 空。視線の向きから色を返す関数で、階調・太陽・星（格子ごとに 1 点、等級はべき分布）・天の川・雲（2 層）・流れ星を計算します。同じ関数を空のドーム・水面（反射した向きで）・板のガラスと鋼が呼ぶので、映り込みの中の星まで点のまま描けます。見た目は時刻（0 = 夕方、0.5 = 深夜、1 = 朝）ごとの手作りのキーを CPU で補間して uniform に渡します。
- `src/stage/Water.ts` — 水面。空は反射方向で直接計算し、板と文字だけを平面反射（`reflector()`）のパスで描いて重ねます。反射パスは空を描かない（レイヤーで除外）ので透明のまま残ります。面の傾きは、風の強弱つきの 3 段のさざ波と、触れた点から広がる輪の合計。手前ほど映り込みをぼかします。
- `src/stage/Monoliths.ts` — 作品の板。表紙を内側から光らせ、ガラスと鋼は空を映します。表紙は近い順に読み込み、縦横比が分かったら板の形と停止位置を作り直します。`src/stage/Wordmark.ts` — 立体の題字。輪郭は `tools/hub-wordmark.mjs` が表示用の書体（Syne ExtraBold）から取り出した `src/stage/wordmark.json` で、実行時に押し出します。
- `src/stage/Motes.ts` — 光の粒。位置・速度・色・行き先の 4 本のバッファを GPU の計算パス（WebGPU はコンピュート、WebGL2 はトランスフォームフィードバック）で毎フレーム進めます。ふだんはカメラについて回る空気の箱（60 × 6.4 × 60 m）の中を、渦（カールノイズ）と風に乗って漂い、夕方は逆光で光る塵、夜は蛍のように明滅します。集まる先は「世界に置いた 1 枚の絵」で、`src/stage/targets.ts` が題字・表紙・終章の 1 行を 1 枚のキャンバステクスチャに描き、粒は自分の格子位置でその色と明るさを読んで行き先を決めます（暗い所には集まりません）。絵の明るさは「1 画素に何個の粒が重なるか」から決めるので、粒の数・距離・画面の大きさが違っても同じ明るさに見えます。加算で重ねる粒は反射パスのアルファを書かず（水面は「アルファがある所＝物がある」と読むため）、解像度の低い反射パスの中では粒を大きく・暗く描いて、映り込みが角ばるのを防ぎます。
- `src/stage/layout.ts` — 板の配置と、カメラの停止位置の計算（three.js に依存しない純粋な計算）。板の四隅を画面に投影し、決めた枠に収まるまでカメラを下げます。`npm run test:hub` が、8 通りの画面の形で「どの作品も枠に収まる」「手前の板に隠れない」「カメラの道が板や題字を突き抜けない」を検査し、Pages 公開時にも実行します。
- `src/audio/Soundscape.ts` — 生成音。`src/components/` — ローダー・カーソル・作品名・レール・詳細・索引・終章・計器表示。`src/fit.ts` — 幅の広い表示用書体を、列に収まる大きさへ実測で合わせます。
- 確認用のクエリ: `?gl=1`（WebGL2 を強制）、`?tier=ultra|high|mid|low`（画質の段階）、`?motion=full|reduce`（動きの設定を上書き）、`?dbg=nopost`（後処理なし）、`?dbg=nomotes`（光の粒を集めない）、`?dbg=static`（WebGL が無い環境の表示）、`?dbg=scrim`（文字の下の陰りを強調）。開発中は `window.__unfiled.stage` から `tuning`（時刻の固定 `setHour(0..1)`・補間を飛ばす `snap()` など）・`step(dt)` が使え、`window.dispatchEvent(new Event("unfiled:sync"))` でスクロール位置を即時反映、`window.__unfiled.tick()` で GSAP を 1 歩進められます（描画フレームが止まる環境の検査用）。

## 作品を追加・更新する

`public/projects.json`の配列を編集します。1作品につき1オブジェクトを追加してください。`id`は重複しない値にします。下記は入力形式の例です。

```json
[
  {
    "id": "nagi",
    "title": "NAGI",
    "subtitle": "あの日の、海。",
    "description": "時刻と天候を変えながら、桟橋を歩き、ラジオを聴く海辺。",
    "category": "WORLD",
    "year": "2026",
    "url": "https://xenithone.github.io/nostalgic-sea/",
    "source": "https://github.com/XenithONE/nostalgic-sea",
    "cover": "images/nagi.webp",
    "accent": "#8dd6c1"
  }
]
```

| 項目          | 内容                                    |
| ------------- | --------------------------------------- |
| `id`          | 半角英数字とハイフンの識別子            |
| `title`       | 作品名                                  |
| `subtitle`    | 短い副題                                |
| `description` | 作品の紹介文                            |
| `category`    | 作品の分類名                            |
| `year`        | 制作年                                  |
| `url`         | 実際の作品を開くHTTPS URL               |
| `source`      | 公開ソースコードのHTTPS URL（任意。省略するとソースへのリンクを表示しません） |
| `cover`       | `public/`を基準とした表紙画像の相対パス |
| `accent`      | 作品を表す色（例：`#8dd6c1`）           |

画像は`public/images/`へ置き、`cover`には先頭の`/`を付けずに指定します。表紙は一覧のサムネイルのほか、水鏡に立つ板にそのまま映されます（板の形は表紙の縦横比に合わせます。横長でも縦長でも構いません）。JSONの末尾の余分なカンマに注意してください。更新後は`npm run build`で確認し、`main`へpushすると公開内容も更新されます。

表紙は、作品の空気感を表現するオリジナルの生成ビジュアルを使用しています。YOHAKU、IGNIS、TIDAL FORGE、PIGMENTの表紙には実際の作品画面を使用しています。TIDAL FORGEはWebGPUで描画したブラックホールのシーンPNGをそのまま掲載しています。PIGMENTは実際に描画した油彩の3D風景を掲載しています。各作品のリンクから実際のサイトを開けます。

## GitHub Pagesへ公開する

公開先の想定は`XenithONE/unfiled`、URLは[UNFILED](https://xenithone.github.io/unfiled/)です。初回デプロイが成功してからアクセスできます。

1. このフォルダーの内容を、GitHubの`XenithONE/unfiled`リポジトリのルートへpushします。`package-lock.json`も含めます。
2. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。[GitHub公式の公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
3. `main`へのpush、または **Actions → Deploy UNFILED to GitHub Pages → Run workflow** で公開します。成功するとデプロイ結果に公開URLが表示されます。

`.github/workflows/deploy.yml`が`npm ci`と`npm run build`を実行し、`dist/`をPages用アーティファクトとしてアップロードして公開します。公開ジョブはビルドの成功後に実行されます。ワークフローの構成・権限・環境設定は[GitHub公式のカスタムワークフロー](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)に基づき、Node.jsの準備には[actions/setup-node](https://github.com/actions/setup-node)を使用しています。

Viteの`base`は`'./'`を使用します。画像とデータも相対パスで参照し、`/unfiled/`のようなプロジェクト配下から開ける構成です。

TIDAL FORGEは、同じPagesサイト内の`experiments/tidal-forge/`で公開します。`public/experiments/tidal-forge/`にはアプリの配布用静的ビルドを置き、UNFILEDのビルド時にそのまま配信先へコピーします。更新時はこのフォルダーを新しい配布用ビルド一式で置き換えます。WASM、WGSLシェーダー、銀河衝突の軌道データを含むため、一部のファイルだけを更新しないでください。元のソースリポジトリは非公開のまま、作品紹介には公開ソースへのリンクを掲載しません。

RUSTWHIRL ENDLESS 0.4は `public/games/rustwhirl/` から配信する独立したGodot製Webゲームです。無限WAVE、7種の通常敵、12種の装備、5WAVEごとのボス、端末内の上位5記録を備えます。WASM・PCK・JavaScript・音声ワークレットを一式で管理し、既存のPagesワークフローが `dist/games/rustwhirl/` へコピーして公開します。シングルスレッド版なので追加の分離ヘッダーやService Workerは不要です。公開前に戦闘・進行・保存・UIの116項目を検証済みです。

更新はローカルの `game/rustwhirl` プロジェクトで `tools/build_web.ps1` を実行し、最新メニューのキャプチャを `builds/web-captures/menu.png` に生成した後、このリポジトリの `tools/sync-rustwhirl.ps1` を実行します。同期スクリプトは配布物のSHA-256を確認してからコピーします。作品一覧の紹介は `public/projects.json`、同梱の操作説明とライセンスはゲームフォルダー内の `README_JA.md` と `THIRD_PARTY_NOTICES.txt` です。スコアはブラウザ内保存で、オンライン共通ランキングではありません。

「天井のむこう」は `public/comics/tenjou-no-mukou/` にある独立した静的Web漫画です。HTMLの台詞、オリジナルのカラー漫画画像、CC0収録素材を編集した割れ物・機械式電話・床板の軋み・喉の声と、Web Audioの効果音を使用します。「読みはじめる」のクリックで音を有効にし、人影を見たあとの新しい下向きスクロールで36コマの高速自動演出を開始します。最後は顔と片手の大きな専用画像に切り替わります。画面を離れる、停止ボタンを押す、Escapeを押すと演出を終了できます。音・動きの切り替えは設けず、毎回の「読みはじめる」で両方を有効にしてから本文を表示します。端末の動きを減らす設定では自動的にOFFにしません。停止後の再読でも両方が有効に戻ります。

## FUDE — 人も、AIも、同じ筆で。

- 共有: 台本は `?play=…` のリンクにでき、開くと描く様子が再生されます。

## AIPOLLO 11 — 4 つの AI、月へ行く。

[AIPOLLO 11](https://xenithone.github.io/unfiled/films/aipollo11/)は `public/films/aipollo11/` にある独立した静的な短編アニメーション（約 4 分）です。Claude・GPT・Gemini・Grok の 4 人が、失敗を重ねながらロケットを作って月へ行く、アポロ 11 号のパロディ。three.js r187（`WebGPURenderer`）と TSL で、地球（大陸・雲・大気を最初に GPU で地図に焼く）、打ち上げの煙（計算シェーダーの 3 次元流体シミュレーション）、体積の炎、月面、光の筋や霧までをその場で描きます。画像生成・動画生成・素材ファイルは使っていません。音も Web Audio の合成で、すぐ再生できるよう合成結果を圧縮した `audio.opus` を同梱しています（`?audio=live` でその場合成）。`?q=high` で高品質。WebGPU が必要です（パソコンの Chrome / Edge）。
