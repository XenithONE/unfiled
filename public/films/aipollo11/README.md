# AIPOLLO 11

アポロ 11 号のパロディ短編。Claude・GPT・Gemini・Grok の 4 人が、失敗を重ねながらロケットを作って月へ行く。
絵・動き・煙・炎・地球・月・文字・音のすべてを、コードがその場で作っている（画像生成・動画生成・素材ファイルなし）。

- 描画：three.js r187（WebGPU / TSL）。`vendor/three` に同梱（MIT ライセンス）
- 音：WebAudio で合成。すぐ再生できるよう、合成した結果を圧縮した `audio.opus` を同梱している。
  `?audio=live` を付けて開くと、保存済みを使わずその場で合成する（数十秒かかる）
- 画質：`?q=high` で高品質（煙の格子・地球の地図・光の筋が細かくなる）
- 操作：スペース＝一時停止、←→＝5 秒移動、H＝時刻表示、F＝全画面
- WebGPU が必要（パソコンの Chrome / Edge の最新版）

登場する名言は、アームストロング船長の言葉へのオマージュ。各キャラクターは各社の公式マスコットをもとにしたパロディ（Gemini だけはアイコンの四芒星からの創作）で、各社とは関係のない非公式の作品。
