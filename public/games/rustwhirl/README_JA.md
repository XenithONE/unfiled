# RUSTWHIRL ENDLESS 0.4

敵弾を吸い込み、回収したガラクタごと投げ返す耐久スコアゲームです。倒されるまでWAVEが続き、5 WAVEごとに大型破砕機が出現します。

## 操作

|操作|キーボード・マウス|
|---|---|
|移動|WASD|
|振り回す|左クリック / J|
|吸引|右クリック / K を長押し|
|投擲|吸引を離す|
|ダッシュ|Space|
|一時停止|Esc / P|

パッドは左スティック移動・右スティック照準・RT/RB攻撃・LT/LB吸引・A回避。タッチ画面は横向き推奨。左パッドで移動、右のボタンで吸引・振り回し・回避、照準は近い敵へ自動で向きます。白い鉄弾は吸えます。地面の赤い予告は回避してください。満載時には追加の弾を吸えません。

## 0.3からの変更

- 有限4ステージから無限WAVEへ。通常WAVEは規定時間と撃破数の両方を達成して突破、ボスWAVEは大型機を撃破して突破します。
- 通常敵を3種から7種へ。追跡・射撃・突進に、予告線から高速弾を放つ狙撃機、地面に爆発予告を置く地雷機、撃破後に2機へ分裂する機体、近接攻撃を軽減する装甲機を追加。
- 新敵は既存のアニメーション素材をもとに、色・装着部品・名前で区別した派生機体です。
- 装備は6種から12種へ。それぞれ2段階まで強化可能。推進タービン、偏向装甲、冷却コイル、解体ブレード、収束レンズ、選別センサーを追加しました。
- 装備強化が埋まると、繰り返し選べる応急整備で耐久3回復とWAVE×250点を得て続行できます。
- 敵の体力、移動速度、出現数、出現間隔、弾速が段階的に上がります。ボスの弾幕も後半で増えます。通常敵の同時数は28体、敵弾生成時の弾数上限は240です。
- 撃破・連鎖・WAVE突破・整備精算で得点。戦闘画面にスコアを常時表示します。
- 最高スコア、最高到達WAVE、最長生存時間、上位5記録を記録帳に保存します。

## 保存

記録・設定・WAVE開始時の中断データは、このサイトのブラウザ内ストレージに保存されます。オンラインの共通ランキングではありません。ブラウザのサイトデータを削除すると記録も消えます。保存できない場合はゲーム内に通知します。途中再開はWAVE開始時に戻ります。敵・弾の途中位置は保存しません。0.3のWindows版とは別の保存領域です。

## Web実行・公開

WebGL 2とJavaScriptが利用できるブラウザで、HTTP/HTTPS経由で開いてください。index.htmlのファイル直接起動には対応しません。初回にエンジンとゲームデータを読み込みます。「ゲームを起動」を押すと工房が開きます。

Godot 4.7.2のシングルスレッドWebテンプレートを使用します。GitHub Pagesで特別なクロスオリジン分離ヘッダーを要求しません。ビルドは `tools/build_web.ps1`、配布物は `builds/web/` と `builds/Rustwhirl-0.4-Web.zip` です。Webテンプレートの取得は `tools/fetch_export_templates.py --web`。素材・フォント・エンジンのライセンスは配布物の `THIRD_PARTY_NOTICES.txt` に同梱しています。

再現可能な検証スクリプトは `tests/endless_checks.gd`、`tests/workshop_checks.gd`、`tests/workshop_ui_checks.gd` です。UI検証は描画可能なGodot環境で実行してください。
