# 天井のむこう — 効果音の素材

本ページの音は、以下のCC0収録素材を編集した48 kHz / 16 bit PCM音源と、独自のWeb Audio効果音で構成しています。映画の音声は使用していません。音源は漫画と一緒に配信され、再生時に外部の音声サービスへ接続しません。

| 配信用ファイル | 収録素材 / 作者 | 編集内容 |
| --- | --- | --- |
| shatter.wav | [Plate Break 1.wav — jc.sg](https://freesound.org/people/jc.sg/sounds/565642/)、[Ceramic_Break.wav — Brsjak](https://freesound.org/people/Brsjak/sounds/623130/) | 皿の破砕、破片の跳ねる音を重ね、近距離の響きに調整 |
| phone.wav | [telephonering.wav — transitking](https://freesound.org/people/transitking/sounds/15826/) | 機械式ベルを切り出し、2回の長い着信と金属の余韻を編成 |
| wood.wav | [Wood Creak Single V7 — Rudmer_Rotteveel](https://freesound.org/people/Rudmer_Rotteveel/sounds/506662/) | 床板が沈む軋みを低くし、重さと短い反響を追加 |
| voice.wav | [spooky groan.wav — jenmshaw](https://freesound.org/people/jenmshaw/sounds/636270/)、[groan.mp3 — Kneeling](https://freesound.org/people/Kneeling/sounds/473525/) | 声の混合、ピッチ変更、母音の共鳴、途切れる喉の震え、短い反射音を追加 |

各配布ページの [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 表示を2026-09-13に確認。Kneelingの素材は [niittymaaのCC0音源](https://freesound.org/people/niittymaa/sounds/354160/) の加工として配布されています。

元データはFreesoundの公開HQ MP3。配信用WAVへの変換で元録音の解像度が増えるわけではありませんが、編集後の再圧縮を避けています。再現用の編集コードは `design/tenjou-no-mukou/master-sound.py` にあります。
