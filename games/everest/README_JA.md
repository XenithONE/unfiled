# EVEREST — WHITE RUSH

Three.jsで描くスノーボードの自由滑走ゲーム。エベレスト山頂から、麓のベースキャンプを目指します。実測地形の再現ではなく、爽快感を優先して構成した山岳フィールドです。約3 km幅の山肌を自由に旋回・横断できます。指定ルート、コースの柵、必須チェックポイントはありません。

## 遊び方

- A / D または ← / →：旋回。離すと緩やかに下り方向へ安定します。
- SPACE：ジャンプ。自然の雪庇でも自動でジャンプします。
- X：空中トリック。繰り返すと720 / 1080。着地姿勢は自動で補正します。
- SHIFT：ブースト。トリック、ニアミス、イベント脱出でエネルギーが回復します。
- S / ↓：ブレーキ。ESC：休憩（オンラインでは滑走が続きます）。
- スマートフォン：画面の操作ボタン。ゲームパッド：左スティック / Aジャンプ / Xトリック / RTブースト / Bブレーキ。

方位ガイドと麓の光がベースキャンプを示します。ゴールは山の最下部、キャンプ周囲150 mです。横へ大きく迂回した場合は、最後にキャンプへ進路を戻してください。岩やクレバスに当たっても短時間で復帰できます。雪崩、氷塔崩落、追い風の発生位置と組み合わせは毎回変わります。

## マルチプレイ

オンラインは最大4人。ホストがルームを作り、6文字のコードか招待URLで合流します。全員の通信同期後にホストがスタート。全員が到着すると再戦できます。参加者同士の衝突はありません。滑走中の新規参加は受け付けません。

PeerJS Cloudの公開シグナリングサービスとWebRTCを使用します。ライダー名、滑走位置、姿勢、スコアを参加者間で送受信します。専用TURNサーバーは契約していないため、企業ネットワークなどのNAT・ファイアウォール条件により接続できないことがあります。ソロとローカル対戦は接続サービスを必要としません。サーバー検証付きの競技ランキングではなく、友達同士で遊ぶカジュアルレースです。

オンラインでは短時間のタブ切り替え中も自動滑走を続け、1分間の離席で退出します。ホストが退出した場合は他の参加者がそのままソロで滑走を継続できます。

ローカル2人対戦は左右の画面分割です。P1：A/D、SPACE、X、左SHIFT、S。P2：←/→、ENTER、/、右SHIFT、↓。キーボードの同時押し制限がある場合はP1でゲームパッドを使えます。

## 実装・検証

`course.ts`が地形と自然物、`sim.ts`が固定120 Hzの滑走、`events.ts`が共有シードの山岳イベント、`render.ts`が描画、`network.ts`がルーム通信を担当します。描画と接地は同じ三角形地形を参照します。雪庇は共通の高さ関数で生成し、先端の高さを保って離陸します。

`node tools/test-everest.mjs`で16項目のシミュレーション検証、`npm run build`で型検査と配布ビルドを実行します。個人のタイム・スタイル最高記録だけをブラウザ内に保存します。保存領域が使えない環境でも滑走できます。
