# FUDE（筆）設計メモ

「人も、AIも、同じ筆で。」 — ブラウザで動く本格的なお絵描きツール。CLIP STUDIO PAINT や Painter のような道具を、人と AI が同じ描画エンジンで使う。

- 公開先: `https://xenithone.github.io/unfiled/tools/fude/`（UNFILED の Vite 追加ページ。入口 `tools/fude/index.html`）
- 依頼（2026-11-21 本人）: 「サイトに乗せる用の web お絵描きツール。painter やクリスタみたいに高度な色んなツールを入れた最高のツール。AI にお絵描きさせたりもするのでそれを込みで」
- 画面の文言はすべて日本語（本人は英語を読まない）。AI 向けの命令名だけ英字。

## 決めたこと（と却下した案）

| 項目 | 採用 | 却下した案と理由 |
| --- | --- | --- |
| 描画 | WebGL2（全レイヤーを GPU のテクスチャで持つ） | Canvas 2D: 混色・指先・水彩のにじみで下の色を読むたびに GPU→CPU の読み戻しが要り遅い。WebGPU: iPad/Safari の旧版で動かない。 |
| 画面 | React（パネル）＋素の TS（エンジン） | 全部素の DOM: パネルが多く状態の同期が壊れやすい。 |
| 色の持ち方 | レイヤー RGBA8（乗算済み）、描画中の筆跡と合成は RGBA16F | 全部 16F: 1 枚 25MB 以上でレイヤーが増やせない。全部 8bit: エアブラシの薄塗りで縞が出る。 |
| 取り消し | 256px の区画ごとに「描く前」を GPU 上へ写す（必要な区画だけ） | 毎回レイヤー全体を保存: メモリが足りない。CPU に読み戻し: 1 筆ごとに止まる。 |
| AI の描き方 | JSON の「台本」（SVG のパス文字列で線と面）。人の筆と同じエンジンで、1 本ずつ描く様子を再生 | AI に JS を書かせて eval: 公開サイトで任意のコードが動き危険。画像生成 AI を呼ぶ: お絵描きツールでなくなる。 |
| AI との接続 | ①AI への指示をコピー → 返事を貼る（SCENE FORGE と同じ方式）②ブラウザを操作できる AI は `window.fude` を直接呼ぶ | サイトから AI の API やローカルサーバーへ自動で通信: UNFILED の方針（公開サイトから外へ勝手に通信しない）に反する。鍵の管理も危険。 |
| 保存 | ブラウザ内（IndexedDB）へ自動保存＋ファイル書き出し（PNG/JPEG/WebP/PSD/ORA） | サーバー保存: 静的サイトなので無い。 |

## 座標の約束
- キャンバス座標: 左上が原点、y は下向き、単位は画素。
- テクスチャの 0 行目＝キャンバスの最上段（FBO へは y を反転せず ndc.y = y/H*2-1 で描く）。`readPixels` の 0 行目も最上段、画像の `texImage2D` も反転なし。
- 画面への表示だけが y を反転する（表示パスの行列）。

## エンジンの層
- `engine/gl.ts` WebGL2 の下回り（プログラム・テクスチャ・FBO・全画面三角形）
- `engine/doc.ts` 文書とレイヤーの木（ラスター／フォルダー／テキスト）。マスク、クリッピング、透明ピクセルのロック、参照・下描き
- `engine/compositor.ts` 合成。汚れた矩形だけ合成し直す（シザー）。描画中のレイヤーは「中身の差し替え」（筆跡・フィルターの試し・変形の試し）で見せる。合成モード 27 種（CLIP STUDIO の一覧に合わせる）
- `engine/brush/*` 筆。3 方式:
  - stamp: 判子を筆跡バッファ（16F）へ重ね、離した時にレイヤーへ確定。入り抜き・筆圧・粒状（紙の目）・散布・色の揺らぎ・重ね方（over＝重ねると濃く／max＝一筆の中では濃くならない）
  - mix: 判子ごとにレイヤーを直接書き換える（指先・ぼかし・油彩）。下の色を拾って運ぶ
  - water: stamp＋下の色を拾う混色＋離した時の水彩の縁（にじみの濃い縁）
- `engine/undo.ts` 区画単位の取り消し（GPU のアトラスに保存・上限を超えたら古い順に捨てる）
- 選択範囲は R8 のテクスチャ。点線（境界の動く線）は表示パスのシェーダーで描く
- 塗りつぶし・自動選択は CPU（読み戻し → 走査線の塗りつぶし → 隙間閉じ・領域拡縮 → マスクを上げる）

## AI の台本（FUDE Script）
- `{"size":[W,H], "ops":[ {"op":"layer",...}, {"op":"brush",...}, {"op":"stroke","d":"M..."}, ... ]}`
- 座標は台本の `size` の空間。今のキャンバスへ縦横比を保って収める（SVG の viewBox と同じ）。
- 1 回の実行が取り消し 1 回分。再生は人が描く速さで 1 画ずつ（`say` で字幕）。
- 詳細の仕様と AI 向けの説明文は `src/ai/spec.ts` が唯一の出典（画面のヘルプ・コピーする指示文・`fude.help()` はここから作る）。

## 検証
- 純粋な部品（SVG パス、台本の検査、塗りつぶし、PSD/ZIP）は Node 24 の型除去でそのまま TS を実行して試す（`tools/test-fude.mjs`）。
- 画面は Browser pane で `window.fude` を叩き、画素を読んで数値で確かめ、スクリーンショットで目でも見る。
- Browser pane が隠れていると rAF が止まるので、`fude.flush()` で合成と表示を同期で行える。

## まだの所（次に足すなら）
- ベクターレイヤー、メッシュ変形・ゆがみ（液化）、色調補正レイヤー（非破壊）、境界効果（非破壊のフチ）

- 筆先の画像の読み込み（今はコードで作った 14 種）
- キャンバスの大きさ変更・回転は取り消せない（実行前に元の絵を作品一覧へ残す）
